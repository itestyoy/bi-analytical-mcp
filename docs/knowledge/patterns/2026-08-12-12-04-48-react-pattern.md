# ReAct Pattern

## Status

Active

## Problem

Multi-step work can drift when the agent reasons in isolation and only later tries to act, or when it acts without updating its plan from fresh observations.

## Pattern

- Restate the goal and the current question before taking a tool-backed step.
- Alternate between a short reasoning step and an action step.
- Capture the observation from the action before deciding what to do next.
- Update the working plan when the observation changes the situation.
- Use this loop when external facts, tools, or system state matter.
