# Two-Agent Eval — 30 HARD Tasks

Second round, all tasks **hard** (no easy/medium filler). Agent A (analyst) saw ONLY
`config/catalog.yml`; Agent B (engineer) saw ONLY the tool JSON-Schemas. Solutions
in `2agent-30-hard-solutions.md`.

1. **D1/D7/D30 retention curves by acquisition channel** — stickiest `media_source`? — `install_date`+`media_source` cohort × `new_session` days-since-install → retention grid. *Hard:* relative-time offset per user, presence-not-count.
2. **Time-to-first-purchase survival by install week** — how long until payers convert? — first `iap_purchase_completed` vs `install_date` (week) → survival curve. *Hard:* first-per-user, censoring, survival math.
3. **Rolling 7-day active users** — engagement trend minus weekday noise? — distinct `appsflyer_id` (`new_session`)/day, trailing-7d rolling distinct → daily series. *Hard:* distinct can't be summed across days.
4. **DAU/MAU stickiness by platform** — habitual engagement per `platform`? — distinct active/day ÷ distinct/trailing-30d, by platform → ratio series. *Hard:* ratio of two differently-windowed distinct counts.
5. **Level-N attempt-to-give-up curve** — which level is a difficulty wall? — `level_started`/`level_completed` (`level_id`,`result`,`attempt`): max attempt + never-won → give-up prob by level_id. *Hard:* per-user-per-level reduction + conditional detection.
6. **Funnel conditioned on prior tutorial completion** — does finishing tutorial lift first-purchase? — `tutorial` final `step_id` split → conversion to first `iap_purchase_completed` → two-arm comparison. *Hard:* cohort split by prior flag, forward conversion after the conditioning event.
7. **Churn-and-resurrection by cohort** — what share of churned return, gone how long? — per-user `new_session` gaps; churn = gap>14d then return → resurrection rate + gap distribution by cohort. *Hard:* inter-event gaps + state transitions over ordered sequence.
8. **LTV-to-date by install week (IAP + ad blended)** — most valuable install weeks? — `price_in_usd` + `ad_finished.revenue` per user, cohort by install week → cumulative LTV by days-since-install. *Hard:* two streams/units/grains, relative-time cumulative, cohort grid.
9. **Reward-economy balance by source_type** — which sources inflate/drain coins? — `currency_income.amount` vs `currency_outcome.amount` by `source_type` → net flow + faucet/sink ratio. *Hard:* two events aligned on a key with signed netting.
10. **Pay-after-ad-watch attribution window** — do rewarded ads precede purchases (≤N min)? — `ad_finished ad_type=rewarded` vs later `iap_purchase_completed` per user within window → attributed rate vs baseline. *Hard:* per-user forward time-window matching + counterfactual.
11. **Price-tier migration across purchases** — do payers trade up/down? — ordered `price_in_usd` per user → tiers → tier(k)→tier(k+1) transition matrix. *Hard:* per-user ordering + adjacent-pair transitions from binned value.
12. **Whale revenue concentration (top-x% share)** — revenue concentration risk? — revenue/user (`price_in_usd`), rank, cumulative share of top 1/5/10% → Lorenz curve. *Hard:* per-user agg + ranking + cumulative share over ranked dist.
13. **Session-depth distribution by acquisition_type** — do paid users play shorter? — events between `new_session`/`end_session` per `session_number`, count of `level_started`/`screen_changed` → p50/p90 depth by `acquisition_type`. *Hard:* session-bounding by paired start/end events.
14. **First-session funnel: launch → first level win** — where do brand-new users drop? — within `session_number`=1: `first_launch`→`tutorial`→`level_started`→`level_completed(win)` → funnel. *Hard:* ordered funnel restricted to first session.
15. **Median time-to-complete progression by level** — does difficulty scale smoothly? — `level_completed.complete_time` (win only) by `level_id` → p50/p90 curve. *Hard:* per-level percentile + spike detection along progression.
16. **Ad-watch fatigue: revenue per impression decay within session** — does ad value drop with more ads/session? — `ad_finished.revenue` by within-session impression ordinal → avg revenue by ordinal. *Hard:* per-session impression ordinal then decay.
17. **Conditional retention: payers vs non-payers D14** — how much more do early payers retain? — flag any `iap_purchase_completed` in first 3 days post-install → D14 `new_session` retention → arm delta. *Hard:* time-bounded conditioning flag + relative-time D14 per arm.
18. **Resurrection incrementality of ad rewards** — do post-lapse ad watchers return more? — lapse (gap) then next active day has `ad_finished ad_type=rewarded` → return-retention conditioned on post-lapse ad. *Hard:* gap detection chained to conditional behavior at resurrection.
19. **Coin balance trajectory (running economy per user)** — idle hoards or starvation? — running cumulative `currency_income.amount` − `currency_outcome.amount` by `device_time` per user → end-balance distribution + share hitting zero. *Hard:* per-user signed running-sum over two interleaved events.
20. **Shop_opened → purchase by placement context** — which entry `placement` converts best? — `shop_opened` then `iap_purchase_completed` within session attributed to preceding `placement`/`screen_from` → conversion per context. *Hard:* attribute conversion to most-recent preceding context event.
21. **IAP failure-then-retry recovery** — how many failed purchases recover; which `product_id` leak? — `iap_purchase_failed` then (or not) `iap_purchase_completed` same product/user within window → recovery rate + lost revenue by product. *Hard:* per-user-per-product failure→success pairing with windowing.
22. **Reward-struct yield: items granted per level** — over/under-distributed `item`s? — unnest `level_completed.rewards` (array<struct> item,qty), sum qty by item × level_id → yield distribution. *Hard:* array-of-struct decomposition before aggregation.
23. **Vocabulary breadth vs retention** — does word breadth correlate with retention? — unnest `words_collected` → distinct words/user bucketed, cross-tab vs D7 retention. *Hard:* array unnest + per-user distinct cardinality joined to relative-time outcome.
24. **Screen-flow drop-off (navigation graph leak)** — which transition loses most before shop? — `screen_changed` (`screen_from`,`screen_to`) transition graph; high-traffic paths never reaching `shop_opened` → edge-weighted drop-off. *Hard:* directed transition graph + terminal-path tracing.
25. **Cohort payback period** — days until paid cohort revenue breaks even? — cumulative per-user revenue by days-since-install, `acquisition_type=paid` by `media_source`/`campaign_id` → days-to-payback. *Hard:* relative-time cumulative + threshold crossing per cohort.
26. **Difficulty-induced ad engagement (fail→rewarded ad)** — do players watch ads right after failing? — `level_completed result=lose` then `ad_finished placement=level_fail` same user/session → fail-to-ad rate by level_id. *Hard:* adjacency sequence keyed on placement per level.
27. **Weekly active composition: new/retained/resurrected** — is WAU growth acquisition or reactivation? — weekly distinct active (`new_session`) classified vs prior weeks + `install_date` → stacked weekly composition. *Hard:* multi-state per-user-per-week classification with lookback.
28. **Ratio-of-ratios: paid-vs-organic conversion lift by country** — where does paid over/under-perform organic? — conversion (`iap_purchase_completed`/user) by `acquisition_type` within each `country`, then paid/organic ratio → country lift index. *Hard:* ratio of two segment rates within each country, small-denominator guards.
29. **Hour×weekday engagement heatmap by region** — when to schedule live-ops per region? — `new_session` `device_time` → hour-of-day × weekday, distinct users/cell by `region` → 7×24 heatmap. *Hard:* timestamp decomposition into two cyclic dims + distinct/cell.
30. **Spend-velocity acceleration** — are repeat payers accelerating (gaps shrinking)? — ordered `iap_purchase_completed`/user, inter-purchase gaps, compare gap(k→k+1) vs gap(k-1→k) → share accelerating + median gap by ordinal. *Hard:* per-user ordered gaps + second-order (change-in-gap) comparison.
