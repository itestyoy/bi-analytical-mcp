# Working Note Template

Use this template for reversible local notes when a task needs a trail of conclusions, dead ends, and next steps.

## Context

What is being worked on and why it matters.

## Hypothesis

Initial guess about the best path or the likely cause.

## Investigation

What was checked, observed, or measured.

## Dead Ends

Approaches that were rejected and why.

## Current Decision

The current best choice and the reason for it.

## Next Step

The next smallest safe action.
