# English Language Standard for AGENTS.md Files

## Status

Active

## Last Reviewed

2026-07-22

## Context

The repository needs a consistent language for `AGENTS.md` files so the agent instructions are easy to read and follow across the workspace.

## Decision

All `AGENTS.md` files inside this project must be written in English.

Project notes, summaries, and other knowledge documents may use the language that best fits their audience, but `AGENTS.md` remains the English procedural layer.

## Consequences

- Agent instructions are easier to scan and reuse across repositories.
- The procedural layer stays consistent even when other knowledge notes use a different language.
- Future updates to `AGENTS.md` files should stay in English by default.

## Affected Scope

- `AGENTS.md` at the repository root
- `docs/knowledge/**/AGENTS.md`
