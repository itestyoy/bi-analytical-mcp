# Navigation

Fast entrypoints.

- Read first.
- Keep them short, linked, and updated.
- Use `Parent`, `Children`, and `Related` when helpful.
- Start new navigation maps from [`../templates/navigation-template.md`](../templates/navigation-template.md).
- Keep navigation documents as fixed map files in this directory.
- Do not rename them into dated note paths.

## Files

- `SYSTEM.md` - top-level system summary
- `REPOSITORY_MAP.md` - repository and folder map
- `API.md` - API surface map
- `DATABASE.md` - database and schema map
- `EVENTS.md` - events, jobs, queues, and async flows
