# Working Note Example

## Context

Task refinement skill needs a reusable note trail so I can move between findings without losing the investigation thread.

## Hypothesis

A short reversible note with conclusions and dead ends will make it easier to refine a task plan and recover after blockers.

## Investigation

- Checked the current skill flow.
- Confirmed the task-template already covers durable task notes.
- Identified a gap for task-local working memory examples.

## Dead Ends

- Copying the full task-template into the skill would add noise.
- Using only narrative guidance would be too vague for repeated use.

## Current Decision

Keep a tiny working-note file for complex tasks, start it from the template, and use this example as the shape to follow.

## Next Step

Create or update a working note whenever the task branches, stalls, or needs to be revisited.
