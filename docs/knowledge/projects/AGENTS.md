# Project Indexes

Compact repo maps.

- Keep one directory per repo.
- Add `AGENTS.md` for each index.
- Keep entries short and linked.
- Treat the root `AGENTS.md` as the router.
- Move dense detail to domain files.
- Split when it stops being compact.
- Store supplemental project notes under `docs/knowledge/projects/<repo>/YYYY-MM-DD-HH-MM-SS-short-title.md`.
