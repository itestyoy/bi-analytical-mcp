# Architecture

## Instructions

- Read `navigation/` first.
- Keep maps short, layered, and linked.
- Start new maps from [`../templates/architecture-template.md`](../templates/architecture-template.md).
- Update the map before deeper notes.
- If you add a new architecture map, store it as `docs/knowledge/architecture/YYYY/MM/YYYY-MM-DD-HH-MM-SS-short-title.md`.
